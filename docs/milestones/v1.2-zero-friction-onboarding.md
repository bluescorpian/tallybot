# Milestone: v1.2 — Zero-Friction Onboarding

Target: a user who has never touched PlatformIO or the Arduino IDE can unbox an
ESP32-C3 SuperMini, plug it in, and have a working, assigned tally light — all from
inside the TallyBot app, in under five minutes.

This milestone completes the **"buy hardware, install app, done"** differentiator
described in [`docs/goals.md`](../goals.md).

---

## Requirements

- App detects an ESP32-C3 when it is plugged in via USB-C
- App can flash TallyBot firmware to the device without any external tools (no
  PlatformIO, no Arduino IDE)
- After flashing, the wizard presents a transport selector with two options:
  - **WiFi** — app provisions SSID + password to the device over USB; device operates
    wirelessly once unplugged
  - **No TX (USB)** — no wireless provisioning; device operates permanently via USB
    cable, receiving tally commands directly from the PC
- Any device, regardless of its provisioned transport, uses USB when plugged in and
  reverts to its wireless transport when unplugged
- A USB-connected device appears on the board alongside WiFi devices, with an
  indicator that it is wired
- Works on Windows and macOS
- WiFiManager SoftAP captive portal is retained as a fallback for field
  re-provisioning of WiFi devices (hold **BOOT** on power-up triggers it when no
  laptop is available)

---

## Acceptance criteria

- Plug in an unflashed ESP32-C3 → app surfaces "new device" prompt within a few
  seconds; no terminal required
- **WiFi path:** select WiFi, enter SSID + password → device is flashed, provisioned,
  reboots, joins WiFi, and appears on the board as a wireless device
- **No TX path:** select No TX → device is flashed and immediately appears on the
  board as a wired device, responding to live tally commands via USB
- Plug in a device already provisioned for WiFi → it appears on the board with a
  wired indicator and responds to tally commands over USB; unplug it → it transitions
  back to WiFi
- Holding BOOT on a deployed WiFi device still triggers the WiFiManager portal
  (field re-provisioning path unaffected)
