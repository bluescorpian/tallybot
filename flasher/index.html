TallyBot Flasher

Turn an ESP32-C3 SuperMini into a tally light, straight from your browser.

You need

  • An ESP32-C3 SuperMini board
  • A USB-C cable that carries data (some charge-only cables don't)
  • Chrome or Edge on a computer. Firefox and Safari can't talk to USB devices.
This browser can't flash devices. Open this page in Chrome or Edge on a computer. Flashing needs a secure page. Open this page over https. Firmware (loading…)

Steps

  1. Plug the board into this computer.
  2. Click Install TallyBot and pick the board from the list (it usually shows as USB JTAG/serial debug unit).
  3. For a brand-new board, let it erase the device first. When updating a light you've already set up, skip the erase to keep its settings.
  4. When it's done the light glows magenta: it's ready to set up. Leave it plugged in, open the TallyBot app, and it appears there.

If the board isn't listed

  • Try another cable or USB port.
  • Put the board into download mode: hold BOOT, tap RESET, let go of BOOT, then try again.
  • Close the TallyBot app or any serial monitor while flashing, as only one program can use the port at a time.
  • On Linux, add yourself to the dialout group (uucp on Arch) and log back in.
